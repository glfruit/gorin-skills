# v2 迁移清单

机器可读权威文件是 [`skills.json`](./skills.json)。清单将每个有效本地技能恰好记录一次，归档目录不计入有效技能。

## 当前状态

- 68 个本地技能：32 个已重新资格审查并迁入 v2，36 个仍为 `legacy-v1`；
- 2 个外部来源以固定 revision 登记；
- 0 个遗留源码可直接分发。剩余 36 个均因来源、许可证或第三方维护边界未解决而被排除；
- `legacy-v1` 配置集现用于选择 32 个 v2 canonical 技能并附带兼容 alias，不会重新发布被排除的遗留源码。

初始盘点是 1 个 v2 + 67 个遗留源码，其中 31 个一度具有可迁移的第一方与许可证证据。它们已经完成迁移，因此不能把初始数字继续解释成当前分发决策。

## 保守边界

`docx`、`pdf`、`xlsx` 的现有条款不允许按本仓库方式保留/复制/分发，因此保持遗留并排除。其他未解决的本地第三方副本也不发布；后续只能在补齐来源证据后转为固定 mirror，或删除本地副本并保留 external 登记。

旧目录与旧 alias 仅支持到仓库 v2 结束。v3 前必须完成删除或外部化，不能无限期把兼容层当成正式来源。
