# Markdown Polish Checklist

## Before

- [ ] Canonical Markdown source confirmed.
- [ ] Exact target files listed.
- [ ] Exact issue classes listed.
- [ ] Code fence count recorded.
- [ ] Table/image/list count recorded when relevant.

## Allowed Changes

- Heading marker repair.
- Code fence closure or language label repair.
- List marker repair.
- Table pipe alignment that preserves cells.
- CJK/English spacing and punctuation cleanup.
- Broken local image path correction.

## Not Allowed

- Whole-chapter replacement.
- Semantic rewriting without a separate content task.
- Removing examples, code, tables, or images without a review item.

## After

- [ ] Changed ranges reviewed.
- [ ] No unrelated section changed.
- [ ] Markdown hygiene check passed.
- [ ] Formatting report saved.
