# gorin-edu-pptx

Provides the Edu Team entry point for creating and editing teaching slide decks.

Use PptxGenJS for editable courseware generated from scratch, OfficeCLI for existing PPTX edits, and the theme references in this skill for teaching-oriented visual consistency.

Do not use this skill for image-only slide cards unless the deliverable explicitly does not need editable PPTX.
