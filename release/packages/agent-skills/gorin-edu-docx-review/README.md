# gorin-edu-docx-review

Reviews textbook DOCX files against publishing and teaching-material quality requirements.

The skill is review-only: it unpacks DOCX structure, checks headings, tables, figures, code, formulas, placeholders, and formatting risks, then writes an actionable Markdown report.

It should not generate or rewrite DOCX files. Use it before teacher review, publisher submission, or when validating that exported DOCX artifacts preserved Markdown source structure.
